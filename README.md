# Plaire Auto-Edit

Автомонтаж роликов Plaire. Каждое утро GitHub Actions берёт исходники с Google Диска и кладёт в папку `Done` готовые ролики 9:16, обложки и подписи. Полная инструкция для Claude лежит в `.claude/skills/plaire-autoedit/SKILL.md`.

## Где мы сейчас

**Фаза 1, шаг 1:** доступ к Google Диску и проверка путей.

| шаг | что | статус |
|---|---|---|
| 1 | доступ к Диску, дерево папок, подтверждение путей | в работе |
| 2 | `brand.json`, валидатор текста, `texts.json` | — |

| 6 | ежедневный запуск по расписанию, 7 дней без сбоев | — |

## Доступ к Google Диску (бесплатно, без Google Cloud)

Вход через rclone: это бесплатная программа, у которой уже есть своё проверенное Google приложение. Платная подписка и Google Cloud не нужны. Вход не истекает сам. Он слетает, только если вы отзовёте доступ в аккаунте Google («Безопасность → Сторонние приложения»).

1. Установите rclone на компьютер: https://rclone.org/downloads/
2. В терминале выполните `rclone authorize "drive"`, войдите в Google в открывшемся браузере, нажмите «Разрешить».
3. В терминале появится строка `{"access_token":…,"refresh_token":…}`. Скопируйте её целиком, от `{` до `}`.
4. Откройте папку Plaire на Диске. В адресе после `/folders/` стоит её ID.
5. Репозиторий → **Settings → Secrets and variables → Actions → New repository secret**:

| имя | что вставить |
|---|---|
| `GDRIVE_OAUTH_TOKEN` | строка из пункта 3 |
| `GDRIVE_ROOT_ID` | ID папки Plaire из пункта 4 |
| `ANTHROPIC_API_KEY` | ключ с https://console.anthropic.com (нужен с шага 3) |

6. **Actions → «Проверка Диска» → Run workflow.** В отчёте запуска появятся дерево папки Plaire и результат проверки записи. Скрипт создаёт только файл `_autoedit_state/healthcheck.txt` и больше ничего не меняет.

Запасной вариант (если когда-нибудь понадобится): сервисный аккаунт Google Cloud, секрет `GDRIVE_SA_JSON`. Писать в обычный «Мой диск» он не может, поэтому сейчас не используется.

## Правила

- Система **ничего не публикует**. Она только кладёт файлы в `Done`.
- На Диске она пишет только в `Done` и `_autoedit_state`. Исходники, `3D`, `SFX` и `Music` не трогает.
- Секреты не попадают ни в код, ни в логи.
