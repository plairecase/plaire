# Видео 9:16

Мастер-файл один: **1080×1920, 9:16** — одинаково для TikTok, Reels и Stories. Все размеры ниже даны на этом холсте.

## Сетка кадра

- Поля: слева и справа `safe-side` 120 px. Сверху до `safe-top` 270 px ничего важного нет.
- Зона текста: **x 120…960, y 270…1248**. Ниже y 840 текст заканчивается на x 780, справа колонка кнопок (`safe-rail`).
- Ниже 1248 px (`safe-bottom` 672) — только изображение, без текста, цены и логотипа.
- Обложка ролика: главный текст держим в центре **y 240…1680**, потому что сетки профилей TikTok и Instagram режут обложку до 3:4.

## Структура ролика (15–30 с)

1. **0–1.5 с — хук.** Чехол в кадре с первого кадра; `eyebrow` + `display`, не больше 6 слов.
2. **Факты.** 3–4 плана по 1.5–3 с: один факт — одна выноска (Eco-leather · Holds 2 · Magnetic closure · Ultra-slim).
3. **Доказательство.** Макро шва, тиснения, магнита; чехол в кармане.
4. **Финал.** Вордмарк поверх живого кадра + ценник `€29 | • PLAIRE.EU` + `fine`: *Free shipping to all EU countries*. Без чёрной карточки.

## Движение

| Что | Значение |
|---|---|
| Кривая появления | `cubic-bezier(0.16, 1, 0.3, 1)` — быстрый старт, долгое мягкое торможение |
| Кривая ухода | `cubic-bezier(0.7, 0, 0.84, 0)` |
| Появление текста | 700 мс: из прозрачности + сдвиг 24 px вверх или из размытия 12 px |
| Уход текста | 400 мс, прозрачность |
| Каскад | 70 мс между словами, 140 мс между строками |
| Минимум на экране | 1.6 с, или 3 слова в секунду |
| Камера | медленный наезд 100 → 104% за план; speed ramp 1.0 → 0.5 на макро (60 fps) |
| Переходы | склейка на движении, match cut по чехлу, кроссфейд ≤ 10 кадров; whip — не больше одного за ролик |

**Нельзя:** отскоки, тряска, глитч, зум-рывки, вращающийся текст, печатная машинка, эффекты TikTok.

## Субтитры

Если в ролике есть речь — стиль `subtitle`. На тёмном фоне белый с тенью `text-on-photo`, на светлом `ink`. Не больше 2 строк, по центру, y ≈ 1000–1200, без плашек и обводок.
