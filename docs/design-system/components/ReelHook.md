# ReelHook

Первый кадр ролика: чехол в кадре и короткая фраза-хук, которая читается за 1.5 секунды.

**Состав:** `eyebrow` (бренд и что это) → `display` Light, не больше 6 слов. Текст `ink` на светлом кадре, `on-photo` с `text-on-photo` на тёмном.

**Положение:** x 120, y 300. Блок текста не выходит за x 960 и ниже y 840.

**Движение:** `eyebrow` появляется первым (700 мс), `display` — по словам с каскадом 70 мс. Камера — медленный наезд 100 → 104%.

**От монтажа нужно:** кадр, где чехол виден с первого кадра; фон без пестроты в верхней трети.

**Нельзя:** вопрос-кликбейт, эмодзи, восклицательный знак, текст ниже y 1248.
