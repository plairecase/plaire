# EndFrame

Финальный кадр: вордмарк над чехлом в живом кадре, ценник и условия доставки. Чёрную карточку не используем.

**Состав:** вордмарк 440 px по центру (y 300) → `eyebrow` «Discreet eco-leather case» → чехол → `PriceTag` (y 1090, ниже чехла) → `fine` «Free shipping to all EU countries».

**Цвет:** на светлом кадре — вордмарк `ink`; на тёмном видео — `on-photo` (белый файл).

**Движение:** вордмарк проявляется из прозрачности за 900 мс, без масштабирования; ценник — через 300 мс; держать 2.5–3 с.

**Нельзя:** кнопки «Купить» поверх видео, стрелки вниз, текст ниже y 1248.
