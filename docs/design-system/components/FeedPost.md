# FeedPost

Посты Instagram и фото-карусели TikTok бывают трёх типов: фото товара, типографская карточка `paper` и карточка `cognac`.

**Формат:** 1080×1440 (3:4), поля `space-8` 64 px. Если пост продвигается — 1080×1350 (4:5).

**Типографская карточка:** `eyebrow` PLAIRE сверху слева → `feed-display` Light внизу → `feed-body` `ink-muted`, не больше 2 строк.

**Карточка cognac:** монограмма белым сверху → `feed-display` цветом `paper` → `eyebrow` с ценой.

**Фото:** без текста и логотипа, свет и тень делают всю работу.

**Нельзя:** больше одной мысли на карточке, рамки, градиенты, коллажи.
