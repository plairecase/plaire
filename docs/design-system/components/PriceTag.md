# PriceTag

Ценник — единственное место, где цена и сайт появляются вместе. Он связывает ролик с plaire.eu красной точкой `signal`, как кнопки на сайте.

**Анатомия:** `price` «€29» → вертикальная `hairline` → `eyebrow` «PLAIRE.EU» с точкой `signal` 12 px.

**Варианты:** без заливки на `paper`; светлый на `leather` и тёмном видео; контурная капсула `radius-pill`, 2 px — только поверх фото.

**Положение в кадре 9:16:** x 120, y 1100–1180, правый край ≤ 780. Ниже — строка `fine` «Free shipping to all EU countries».

**Нельзя:** залитые плашки, красный текст, зачёркнутые цены, «SALE».
